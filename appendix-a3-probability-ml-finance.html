    Appendix A3: Probabilistic, learning and finance algorithms

    Solving a Markov chain: stationary distribution and absorption

    Stationary distribution of a chain with transition matrix PPP: solve the linear system πP=π\pi P = \pi πP=π together with the sum of π\pi π equal to 1 (drop one redundant equation and use the normalization instead). Expected time to reach a target set (hitting time): write h(i)=1h(i) = 1h(i)=1 + sum over jjj of P(i,j)h(j)P(i, j) h(j)P(i,j)h(j) for each state iii outside the target, h=0h = 0h=0 on the target, and solve the linear system. Absorption probability into a particular absorbing state: write uuu(iii) = sum over jjj of P(i,j)u(j)P(i, j) u(j)P(i,j)u(j) with u=1u = 1u=1 at that state and 0 at the other absorbing states, and solve.

    Simulating a continuous-time Markov chain (Gillespie method)

    Solves: sample paths of a CTMC or a queue.

    Steps:

    1. in the current state i, draw the holding time from an exponential distribution with rate equal to the total exit rate qiq_{i}qi​
    2. choose the next state j with probability qijq_{ij}qij​ divided by qiq_{i}qi​
    3. advance time and repeat.

    Value iteration and policy iteration (solving an MDP)

    Solves: the best policy for a known MDP. Value iteration: start with any value function VVV; repeatedly update VVV(s) to the maximum over actions a of [reward(s, a) + γ\gamma γ times the sum over next states s' of PPP(s' | s, a) VVV(s')]; stop when the change is below a tolerance; then pick the maximizing action in each state. It converges because the update shrinks distances by the factor γ\gamma γ. Policy iteration: start with any policy; evaluate it by solving the linear system V=r+γPVV = r + \gamma P VV=r+γPV for that policy; improve it by choosing in each state the action that maximizes the one-step lookahead using VVV; repeat until the policy stops changing. It needs few iterations but each requires a linear solve.

    Q-learning and SARSA

    Solves: learn an optimal policy from experience when the transition probabilities are unknown. QQQ-learning steps: initialize QQQ(sss, a) arbitrarily; in the current state sss choose an action a (mostly the one with the highest QQQ, sometimes a random one: ϵ\epsilon ϵ-greedy); observe the reward rrr and next state s'; update QQQ(sss, a) toward the target r+γr + \gamma r+γ times the largest QQQ(s', a'): Q(s,a)=Q(s,a)+αQ(s, a) = Q(s, a) + \alpha Q(s,a)=Q(s,a)+α (target - QQQ(sss, a)); move to s' and repeat. It is off-policy because the target uses the best next action regardless of what is actually done. SARSA uses the next action a' actually chosen in the target, so it is on-policy and learns safer behaviour while still exploring.

    Policy gradient (REINFORCE)

    Solves: learn a parametrized policy directly.

    Steps:

    1. run an episode with the current policy and record states, actions and rewards
    2. for each step compute the return G (sum of discounted rewards from there)
    3. move the policy parameters in the direction of G (optionally minus a baseline) times the gradient of the log⁡\log log probability of the chosen action
    4. repeat. The baseline (for example the average return from that state) reduces variance without adding bias.

    UCB1 and Thompson sampling (bandits)

    Solves: repeatedly choose among arms with unknown reward averages while losing little reward. UCB1 steps: play each arm once; then at time ttt play the arm with the largest value of (its empirical mean) + sqrt(2ln⁡t2 \ln t2lnt divided by the number of times it has been played). The bonus is large for rarely played arms (optimism under uncertainty). Thompson sampling steps (Bernoulli arms): keep a Beta distribution per arm (start Beta(1, 1)); each round, draw one sample from each arm's Beta; play the arm with the largest sample; update that arm's Beta (add 1 to the success count or the failure count).

    Gaussian process regression and Bayesian optimization

    Gaussian process regression steps: choose a kernel; build the matrix K of kernel values between all training inputs and add the noise variance on the diagonal; compute the Cholesky factor of that matrix once; for a new point, compute the vector of kernel values to the training inputs; the predictive mean is that vector times the solved system with the observed outputs, and the variance is the prior variance minus a quadratic form. Cost O(n3)O(n^{3})O(n3) once, O(n2)O(n^{2})O(n2) per prediction. Bayesian optimization loop: fit a GP to the points evaluated so far; maximize an acquisition function over candidate inputs (expected improvement, upper confidence bound, or a Thompson sample from the posterior); evaluate the true function at that point; add it to the data; repeat until the budget is spent.

    Gradient descent and stochastic gradient descent

    Solves: minimize a loss.

    Steps:

    1. start from initial parameters
    2. compute the gradient of the loss
    3. move the parameters a small step (the learning rate) against the gradient
    4. repeat. Stochastic version: compute the gradient on a small random batch of data each step, which is cheaper and still points the right way on average. For a smooth convex loss and a small enough step the error falls like 1k\frac{1}{k}k1​.

    Backpropagation

    Solves: compute the gradient of the loss with respect to every weight in a neural network.

    Steps:

    1. forward pass, computing and storing each layer's outputs
    2. compute the loss
    3. backward pass, applying the chain rule layer by layer from the output: the gradient with respect to a layer's weights uses that layer's input and the gradient arriving from above, and the gradient passed down is that arriving gradient multiplied by the layer's weights and the activation's derivative. Cost about the same as the forward pass.

    k-means clustering and PCA

    k-means steps: choose k initial centres; assign every point to its nearest centre; move each centre to the mean of its points; repeat until assignments stop changing. It always converges to a local optimum of the sum of squared distances, so run it several times. PCA steps: subtract the mean from the data; form the covariance matrix (or take the singular value decomposition of the centred data); the eigenvectors with the largest eigenvalues are the directions of greatest variance; project onto the top few.

    Monte Carlo option pricing

    Solves: price a derivative by simulation.

    Steps:

    1. simulate many paths of the asset price under the risk-neutral measure (for geometric Brownian motion, ST=S0exp⁡((r−σ22)T+σTZ)S_{T} = S_{0} \exp ((r - \frac{\sigma ^{2}}{2}) T + \sigma \sqrt{T} Z)ST​=S0​exp((r−2σ2​)T+σT​Z) with ZZZ standard normal)
    2. compute the payoff on each path
    3. average the payoffs
    4. multiply by exp⁡(−rT)\exp (-rT)exp(−rT). The standard error shrinks like 1 over the square root of the number of paths. Variance reduction: antithetic variates (use Z and -Z together) and control variates (subtract a correlated quantity with known mean).

    Binomial-tree pricing, European and American

    Solves: price an option by backward induction on a recombining tree.

    Steps:

    1. choose the up factor u, down factor d and risk-free gross return R per step
    2. compute the risk-neutral probability q=R−du−dq = \frac{R - d}{u - d}q=u−dR−d​
    3. build the tree of prices forward
    4. set the values at maturity to the payoff
    5. step backwards, at each node setting the value to the discounted expectation (q times the up value plus 1 - q times the down value) divided by R
    6. for an American option, at each node take the larger of that value and the immediate exercise payoff.

    Longstaff-Schwartz (American options by simulation)

    Solves: price American options when a tree is impractical (many dimensions).

    Steps:

    1. simulate many paths of the asset on a time grid
    2. start at maturity with the exercise payoff
    3. go backwards one date at a time
    4. among paths that are in the money at that date, regress the discounted future cash flow on a few functions of the current price (for example 1, SSS, S2S^{2}S2)
    5. this regression is the estimate of the continuation value
    6. on each path, exercise now if the immediate payoff exceeds the estimated continuation value, and update the cash flow
    7. at the end, average the discounted cash flows. It is approximate dynamic programming with regression.
