    Part 3: Machine learning and decision-making under uncertainty

    3.1 Machine learning basics

    Concept primer

    Machine learning learns a function from examples. Almost every question reduces to three ideas: the model class, the loss, and generalization.

    Supervised learning. Given pairs (input, label), choose parameters w to minimize a loss on training data. Regression predicts a number (squared error); classification predicts a class (cross-entropy, which is the negative log⁡\log log probability assigned to the true label). Training uses gradient descent (see the algorithm appendix); each step follows the negative gradient of the loss, computed by backpropagation in neural networks.

    Generalization. What matters is error on new data. A model too simple underfits (high bias); one too flexible memorizes noise (high variance, overfitting). The classic remedies: more data, regularization (penalize large weights), early stopping, dropout, ensembles, and choosing model size by validation. Never tune on the test set: split into training (fit parameters), validation (choose settings) and test (final honest estimate), or use cross-validation. For data ordered in time, always validate on a later period than you train on.

    Evaluation. Accuracy is misleading when classes are unbalanced. Precision is the fraction of predicted positives that are correct, recall the fraction of actual positives found, F1 their harmonic mean. A ROC curve plots true positive rate against false positive rate across thresholds; area under it summarizes ranking quality.

    Model families. Linear and logistic regression (simple, convex, interpretable), k-nearest neighbours and Naive Bayes (simple baselines), decision trees and ensembles (random forests average many trees to cut variance; boosting adds trees that fix earlier errors), support vector machines (maximum-margin classifiers), and neural networks (stacked linear maps and nonlinearities, trained end to end). Sequence models: recurrent networks and LSTMs process one step at a time; transformers use attention to relate all positions directly and are now standard.

    Unsupervised learning. Clustering (k-means) groups similar points; principal component analysis finds the directions of largest variance and reduces dimension; both are covered in the algorithm appendix.

    Logistic regression, k-nearest neighbours, Bayes' theorem, Naive Bayes, LSTMs and attention are the basics worth knowing cold.

    Q2. Explain k-nearest neighbours. What is its cost and what can go wrong?

    Answer. To classify a new point, find the k training points closest to it (usually by Euclidean distance) and take a majority vote of their labels (or average, for regression). There is no training; the cost is at prediction time, O(n d) per query for n points in d dimensions (faster with k-d trees or hashing in low dimensions). Small k gives low bias and high variance (noisy, overfits); large k does the opposite; choose k by cross-validation. Problems: features must be scaled so that no one dominates the distance; in high dimensions distances between points become similar (the curse of dimensionality), so neighbours are no longer meaningful; memory is needed for the whole training set.

    Q3. What is Naive Bayes, and why is it called naive?

    Answer. It applies Bayes' rule: P(class given features) is proportional to P(class) times the product over features of P(feature given class). The 'naive' assumption is that features are conditionally independent given the class, which lets it estimate each feature's distribution separately with few data (for example, word counts per class in spam filtering). The assumption is usually false (the words 'free' and 'offer' go together), yet the classifier often works well because only the ranking of class probabilities matters. Smoothing (adding one to counts) prevents a zero count from wiping out the product.

    Q6. What is attention, and how are embeddings learned?

    Answer. Attention lets a model compute each output as a weighted average of other positions' values, with weights depending on content: for queries QQQ, keys K and values VVV, attention(QQQ, K, VVV) = softmax(QKTd)V\mathrm{softmax} (Q \frac{K^{T}}{\sqrt{d}}) Vsoftmax(Qd​KT​)V. Each position forms a query, compares it with every position's key (dot product), turns scores into weights with softmax\mathrm{softmax} softmax, and averages the values. It allows direct links between distant words and is computed in parallel, unlike a recurrent network. Embeddings map discrete items (words) to vectors; they are learned as parameters by training on a task, such as predicting a word from its context (word2vec) or language modelling in a transformer, so that items used in similar contexts get similar vectors.

    Q7. Why is an LSTM better than a plain RNN? Explain the gates and name an alternative.

    Answer. A plain recurrent network passes a hidden state from step to step; training by backpropagation through time multiplies many Jacobians, so gradients vanish (or explode) over long sequences and the network forgets early inputs. An LSTM adds a cell state that is updated additively, controlled by three gates (each a sigmoid between 0 and 1): the forget gate decides how much of the old cell state to keep, the input gate how much new information to write, and the output gate how much of the cell state to expose as the hidden state. The additive path lets gradients flow across many steps. A GRU is a simpler alternative with two gates; transformers have largely replaced both for long sequences. To reduce the variance of an LSTM model: more data, dropout, weight decay, early stopping, smaller hidden size, and ensembling.

    Q8. Explain bias and variance with an example.

    Answer. Expected test error = bias squared + variance + irreducible noise. Bias is the error from a model too simple to capture the pattern; variance is how much the fitted model changes with a different training sample. Fit data from a smooth curve with a straight line: high bias (misses the curve), low variance. Fit it with a degree-15 polynomial: low bias on the training points, high variance (wiggles to fit noise), so test error is high (overfitting). Regularization, more data, simpler models and ensembling reduce variance; richer models reduce bias.

    Q9. L1 versus L2 regularization.

    Answer. Both add a penalty on the weights to the loss: L2 (ridge) adds λ\lambda λ times the sum of squared weights and shrinks all weights smoothly toward zero; L1 (lasso) adds λ\lambda λ times the sum of absolute values and drives some weights exactly to zero, so it selects features (sparsity). Geometry: the L1 constraint region has corners on the axes, where the loss contours tend to touch it; the L2 region is a ball with no corners. Bayesian view: L2 is a Gaussian prior on the weights and L1 a Laplace prior (maximum a posteriori estimation).

    Q10. Cross-validation: how do you choose a model, and why is random k-fold wrong for time series?

    Answer. In k-fold cross-validation you split the data into k parts, train on k - 1 and test on the remaining one, rotating through all parts, and average the scores; use the average to choose settings, then keep a final untouched test set for one honest evaluation. For time series, random folds put future observations in the training set and past ones in the test set, leaking information and making results look better than they will be live. Use walk-forward validation: train on data up to time t, test on the next block, then move forward; leave a gap (embargo) between training and test data if observations overlap in time.

    Q12. How does a decision tree pick splits? Compare a random forest and gradient boosting.

    Answer. At each node the tree chooses the feature and threshold that most reduces impurity. Gini impurity is 1 minus the sum of squared class proportions: a node with 40 positives and 60 negatives has 1−0.16−0.36=0.481 - 0.16 - 0.36 = 0.481−0.16−0.36=0.48; entropy is the minus sum of plog⁡pp \log pplogp. A deep tree overfits. A random forest trains many deep trees on random resamples of the data and random subsets of features and averages them, which cuts variance. Gradient boosting builds small trees one after another, each fit to the errors (negative gradient of the loss) of the current ensemble, which cuts bias; it often wins on tabular data but needs careful tuning to avoid overfitting.

    Q13. How does backpropagation work, and what are vanishing gradients?

    Answer. See backpropagation for the steps. It applies the chain rule from the loss backward through the layers, reusing intermediate results, so the cost is about the same as one forward pass. Vanishing gradients: when many factors smaller than 1 (for example, the derivative of a sigmoid is at most 0.25) are multiplied through many layers, the gradient reaching early layers becomes tiny and they learn very slowly. Remedies: ReLU activations, careful initialization, normalization layers, residual connections, gated units in recurrent networks, and gradient clipping for the opposite problem of exploding gradients. For optimization basics see gradient descent.

    Q14. Why is machine learning in finance hard?

    Answer. The signal is weak compared with noise, so models overfit easily; relationships change over time (non-stationarity), so patterns that worked stop working; backtests are tested on the same history many times, so the best-looking strategy is often luck (multiple testing); costs such as spreads and market impact can erase small edges; and data contain leakage if future information sneaks in. Good practice: walk-forward testing, realistic costs, simple models as baselines, penalizing the number of trials, and out-of-sample or paper-trading verification before real money.

    3.2 MDPs, reinforcement learning, bandits, optimal stopping and Gaussian processes

    Concept primer

    This section covers learning to make a sequence of decisions, the heart of reinforcement learning (RL) and of many problems in finance. The unifying object is the Markov decision process.

    MDP. States describe the situation; actions are choices; the environment gives a reward and moves to a next state with probabilities that depend on the current state and action. A policy maps states to actions. The value of a policy in a state is the expected total discounted reward, where a discount factor γ\gamma γ below 1 makes later rewards count less. The optimal value satisfies the Bellman equation: the best value of a state equals the best action's immediate reward plus the discounted expected value of what follows. If you know the model, value iteration and policy iteration solve it. If you do not, you learn from experience.

    Learning from experience. Monte Carlo methods average complete returns; temporal-difference methods update a value toward "reward plus discounted value of the next state" after every step (lower variance, some bias). Q-learning learns action values and acts greedily; SARSA evaluates the policy it actually follows. With function approximation (neural networks) learning can become unstable, so deep RL uses replay buffers and target networks. Policy-gradient methods adjust the policy parameters directly in the direction that raises expected return.

    Exploration versus exploitation. An agent must try uncertain options to learn, yet use what it knows to earn reward. The multi-armed bandit isolates this tension: choose among arms with unknown payoffs. The measure of success is regret (reward lost compared with always playing the best arm). Optimism (UCB) and posterior sampling (Thompson) both achieve regret growing only logarithmically in time. The Gittins index shows that, for a discounted bandit with independent arms whose state changes only when played, the optimal policy plays the arm with the largest index, a number computed from that arm alone.

    Optimal stopping. You observe a process and choose one time to stop and collect a reward (selling an asset, exercising an option, hiring a candidate). Solve backwards: the value of continuing is compared with the reward from stopping now, and you stop where stopping is at least as good. Pricing American options is exactly this problem under the risk-neutral probabilities.

    Gaussian processes and Bayesian optimization. A Gaussian process is a distribution over functions: given observations it returns, at any input, a predicted mean and an uncertainty. Bayesian optimization uses it to optimize an expensive function: choose the next point to evaluate by an acquisition rule (expected improvement, upper confidence bound) that balances high predicted value against high uncertainty. This is the same exploration-exploitation idea in a continuous setting.

    This section covers reinforcement learning, bandits and the Gittins index, optimal stopping, Gaussian processes and Bayesian optimization.

    Q2. State the Bellman optimality equation and prove value iteration converges.

    Answer. V*(s)=max⁡(s) = \max (s)=max over actions a of [ r(s,a)+γr(s, a) + \gamma r(s,a)+γ times the sum over next states s' of P(s' given sss, a) V*(s') ]. Define the operator T that maps a value function V to the right-hand side. It is a contraction: for any two value functions V and W, the largest absolute difference after applying T is at most γ\gamma γ times the largest absolute difference before, because the maximum of a function changes by at most the largest change in the function, and the probabilities average the differences. By Banach'sss fixed-point theorem, T has exactly one fixed point V*, and repeated application converges to it from any start, with the error shrinking by a factor of γ\gamma γ each sweep. Policy iteration alternates evaluating a policy (solving a linear system) and improving it greedily; it stops in a finite number of steps for finite MDPs.

    Q3. Q-learning versus SARSA: what is the difference? Do one update.

    The problem: when the transition probabilities are unknown, an agent must learn from experience. Q(s, a) estimates the long-run value of taking action a in state s and then acting well.

    Answer. See Q-learning and SARSA. QQQ-learning updates toward the reward plus γ\gamma γ times the best next action'sss value (off-policy: it learns about the greedy policy even while exploring). SARSA updates toward the reward plus γ\gamma γ times the value of the action actually taken next (on-policy). Worked update: Q(s,a)=0.5Q(s, a) = 0.5Q(s,a)=0.5, reward 1, γ\gamma γ 0.9, best next value 2, step size 0.1. The target is 1+0.9×2=2.81 + 0.9 \times 2 = 2.81+0.9×2=2.8; the new value is 0.5+0.1×(2.8−0.5)=0.730.5 + 0.1 \times (2.8 - 0.5) = 0.730.5+0.1×(2.8−0.5)=0.73. QQQ-learning converges if every state-action pair is tried infinitely often and step sizes satisfy sum of steps = infinity and sum of squared steps < infinity.

    Q4. Monte Carlo versus temporal-difference (TD) learning.

    Answer. Monte Carlo waits until an episode ends and uses the actual total return as the target: unbiased, but high variance, and it needs episodes to end. TD learning updates after every step using the reward plus the current estimate of the next state'sss value, V(s)=V(s)+αV(s) = V(s) + \alpha V(s)=V(s)+α (r+γVr + \gamma Vr+γV(s') - VVV(sss)); the bracket is the TD error. It bootstraps, so it has lower variance and learns online, but its targets are biased by estimation errors. TD(λ\lambda λ) blends the two.

    Q5. Why does reinforcement learning with neural networks become unstable, and what does DQN do about it?

    Answer. The deadly triad: combining function approximation, bootstrapping and off-policy learning can make value estimates diverge. DQN (deep Q-network) uses a neural network for Q and two stabilizers: an experience replay buffer (store past transitions and train on random batches, which breaks the correlation between consecutive samples) and a target network (a slowly updated copy used to compute targets, so the target does not shift every step). Double DQN reduces overestimation: taking the maximum over noisy estimates is biased upward, so one network chooses the action and the other evaluates it.

    Q6. Policy gradients: derive the basic result and explain the baseline.

    Answer. See REINFORCE. For a one-step problem with policy probabilities π\pi π(a), the expected reward is the sum over a of π\pi π(a) r(a); its gradient is the sum of r(a) times the gradient of π\pi π(a), which equals the expectation of r times the gradient of log⁡π\log \pi logπ(a) (since the gradient of π\pi π equals π\pi π times the gradient of log⁡π\log \pi logπ). So you can estimate it from samples: sample an action, observe the reward, and increase the log⁡\log log probability of the action in proportion to the reward. Subtracting a baseline b from the reward does not change the expected gradient (the expected gradient of log⁡π\log \pi logπ is zero, because probabilities sum to 1) but reduces variance. Actor-critic methods learn the baseline with a value function; PPO keeps each update small by clipping the policy ratio.

    Q7. Multi-armed bandits: define regret and explain UCB.

    The problem: you face K slot machines with unknown average payouts and have T plays. Each play gives information and a reward; the tension is between trying uncertain arms (exploration) and playing the best known arm (exploitation). Regret is the reward lost relative to always playing the best arm.

    Answer. Always playing the best arm to date can get stuck on a bad arm; exploring a fixed fraction of the time (ϵ\epsilon ϵ-greedy) gives regret growing linearly in T. UCB1 plays the arm with the highest empirical mean plus a bonus 2ln⁡tni\sqrt{2 \ln \frac{t}{n_{i}}}2lnni​t​​, which is large for rarely played arms: optimism in the face of uncertainty.

    Example: an arm with mean 0.6 played 10 times at time t=100t = 100t=100 has index 0.6 + sqrt(2ln⁡2 \ln 2ln 10010\frac{100}{10}10100​) = 0.6+0.96=1.560.6 + 0.96 = 1.560.6+0.96=1.56. The bonus comes from Hoeffding's inequality: after n plays the true mean is within 2ln⁡tn\sqrt{2 \ln \frac{t}{n}}2lnnt​​ of the estimate with high probability. UCB1's regret grows like (log⁡T)(\log T)(logT) times the sum of 1/gap over suboptimal arms, which is the best possible order (Lai and Robbins). Thompson sampling: draw one sample from each arm's posterior distribution, and play the arm with the largest sample; often as good as or better than UCB in practice.

    Q8. What is the Gittins index?

    The problem: you have several projects (arms) whose state changes only when you work on them, and you can work on one per period; future rewards are discounted. Which should you work on? The surprising answer is that the optimal policy reduces to computing a number for each arm separately.

    Answer. For an arm in a given state, the Gittins index is the best achievable ratio of expected discounted reward to expected discounted time, taken over all rules for when to stop playing the arm. The optimal policy is to always play the arm with the highest index. Example (deterministic arm, γ=0.9\gamma = 0.9γ=0.9): rewards 1, then 10, then 0 forever. Stopping after one play gives ratio 11=1\frac{1}{1} = 111​=1; stopping after two plays gives 1+0.9×101+0.9=101.9=5.26\frac{1 + 0.9 \times 10}{1 + 0.9} = \frac{10}{1.9} = 5.261+0.91+0.9×10​=1.910​=5.26; stopping after three gives 101+0.9+0.81=3.69\frac{10}{1 + 0.9 + 0.81} = 3.691+0.9+0.8110​=3.69. The best is two plays, so the index is 5.26: the arm looks better than its first reward suggests because it leads to a big payoff. Equivalent view: the index is the fixed payment per period at which you would be indifferent between playing the arm and retiring. Why it matters: a joint problem over all arms (exponentially large) splits into separate single-arm problems. Computing the index exactly is expensive for large state spaces, which motivates learning it with reinforcement learning. Restless bandits (arms change even when not played) have no such exact result; the Whittle index is a standard approximation.

    Q9. Optimal stopping: solve a small example and state the general method.

    Q11. How is pricing an American option an optimal stopping problem? Why is early exercise of an American call (no dividends) never optimal?

    Answer. Holding an American option means choosing the best exercise time; under the risk-neutral probabilities, its price is the maximum, over all stopping rules, of the expected discounted payoff. Backward induction on a binomial tree sets each node's value to the larger of the exercise payoff and the discounted expected continuation value; Longstaff-Schwartz estimates continuation values by regression on simulated paths. For a call on a stock with no dividends, a European call is worth at least S−Ke−rT>S−KS - K e^{-rT} > S - KS−Ke−rT>S−K, which is more than exercising now; so waiting (or selling the call) beats exercising, and the American call equals the European call. A put can be worth exercising early when deeply in the money, because the strike received can earn interest.

    Q12. Formulate the timing of a systematic investment plan (SIP) as an optimal stopping problem.

    Q13. What is a Gaussian process (GP)? Compute a posterior by hand.
